# আমার পথঘাট — APK তৈরির নির্দেশিকা

এই ফোল্ডারে অ্যাপের পুরো প্রজেক্ট আছে। কম্পিউটারে কিছু ইনস্টল না করেই GitHub-এর বিনামূল্যের সার্ভারে APK বানানো যায়।

## ধাপ (প্রায় ১০ মিনিট)
1. github.com-এ একটি অ্যাকাউন্ট খুলুন এবং **New repository** দিয়ে নতুন রিপোজিটরি বানান (নাম: amar-pathghat)।
2. এই ফোল্ডারের সব ফাইল ও ফোল্ডার (`www`, `assets`, `.github`, `package.json`, `capacitor.config.json`) রিপোজিটরিতে আপলোড করুন (**Add file → Upload files**)। `.github` ফোল্ডারটি অবশ্যই থাকতে হবে।
3. রিপোজিটরির **Actions** ট্যাবে গিয়ে **Build APK** বেছে **Run workflow** চাপুন।
4. ৫–১০ মিনিট পর কাজ শেষ হলে ওই রানের নিচে **Artifacts** থেকে `amar-pathghat-apk` নামান। জিপ খুললে `app-debug.apk` পাবেন।
5. ফাইলটি ফোনে পাঠান, খুলুন, আর “অজানা উৎস থেকে ইনস্টল” অনুমতি দিন।

## নোট
- এটি ডিবাগ APK, নিজের ও বন্ধুদের ফোনে চালানোর জন্য যথেষ্ট। Google Play-তে দিতে চাইলে সাইনিং কী দিয়ে রিলিজ বিল্ড লাগবে।
- অ্যাপের ডিজাইন বদলাতে `www/index.html` সম্পাদনা করে আবার Run workflow চাপুন।
- আইকন বদলাতে `assets/icon.png` (১০২৪×১০২৪) পাল্টে দিন।
- অ্যাপে লোকেশন ও ক্যামেরার অনুমতি যোগ করা আছে।
